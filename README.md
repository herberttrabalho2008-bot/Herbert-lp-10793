# lp-10793 — Linguagens de Programação (12ºPI)

Repositório de trabalho da UFCD 10793, partilhado com o professor. **Todo o trabalho da disciplina fica aqui**: não há entregas no Teams.

## Como está organizado

```
lp-10793/
  README.md          este ficheiro
  .gitignore         ficheiros que não vão para o GitHub
  aulas/             o trabalho de cada aula
    aula-02.ipynb
    aula-03.ipynb
    ola.py
  fichas/            as fichas de trabalho e de consolidação
    ficha-05.ipynb
```

## Regras

1. **Um ficheiro por aula**, na pasta `aulas/`, com o nome `aula-NN.ipynb`, em que NN é o número da aula com dois algarismos: `aula-03.ipynb`, `aula-10.ipynb`.
2. **As fichas** ficam em `fichas/`, com o nome `ficha-NN.ipynb`, em que NN é o número da aula em que a ficha foi proposta.
3. **Nomes sem espaços, sem acentos e em minúsculas.** `aula-03.ipynb`, e não `Aula 3.ipynb`.
4. **Cada notebook começa por uma célula Markdown** com o número e o título da aula.
5. **A entrega é o commit e o push.** No fim de cada aula, e sempre que trabalhares em casa, grava o trabalho aqui.
6. **Mensagens de commit que digam o que fizeste**: `Aula 6: tipos, comparações e condicionais`, e não `update`.
7. **Não apagues** o trabalho das aulas anteriores.

## Comandos essenciais

```
git pull            # traz as alterações do GitHub para o teu computador (faz isto antes de começar)
git add .           # marca o que alteraste
git commit -m "Aula 6: ..."
git push            # envia para o GitHub
```
